# image.ocr offline benchmark

The initial `image.ocr@1` benchmark uses a repository-authored PNG generated by
`generate_fixture.py`. The generator contains the complete bitmap glyph data,
uses only the Python standard library, and does not depend on system fonts or
third-party images.

Regenerate and verify the fixture with:

```bash
python generate_fixture.py
shasum -a 256 fixtures/ocr-basic.png
skill-eval run ../../implementations/tesseract-ocr --suite offline.yaml \
  --json report.json --markdown report.md --junit report.xml
skill-eval run ../../implementations/paddleocr --suite offline.yaml \
  --json paddleocr.json
skill-eval compare report.json paddleocr.json --output comparison.md
```

The first three cases cover clean, low-contrast, and three-degree rotated
English text containing a project name, decimal version, and ISO date. Future
fixtures should add Chinese, noise, and multi-block reading order without
weakening the deterministic core.

The checked-in [`results/COMPARISON.md`](results/COMPARISON.md) is local
self-tested evidence, not a cross-platform leaderboard. Both reports use the
same suite digest and record their implementation digest and environment.
